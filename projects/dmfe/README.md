## 🚀 Deployment

This static site is production-ready and can be deployed directly to **GitHub Pages**, **Cloudflare Pages**, **Vercel**, or **Netlify**.

### Deploying to GitHub (Private Repository)
1. Initialize Git and commit files:
   ```bash
   git init
   git add .
   git commit -m "Production release: DMFE Solar Energy Website"
   ```
2. Create and push to a private repository using GitHub CLI:
   ```bash
   gh repo create dmfe-solar-official --private --source=. --remote=origin --push
   ```
3. To host a private repository with a custom domain:
   - **Cloudflare Pages** (Free, connects directly to private GitHub repos with free custom domain support & automatic SSL).
   - **Vercel / Netlify** (Free tier supports private GitHub repositories with free custom domains like `yourname.vercel.app` or custom domains).

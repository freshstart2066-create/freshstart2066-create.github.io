BOUNDED BUFFER • OOM PROTECTION

Sliding-Window Memory Management

Custom token budgeting and priority-weighted FIFO turn eviction prevents mobile memory exhaustion while maintaining unbroken tactical context across long operational sessions.

🪟 2,048 Token Maximum Budget

Constrained devices fail when LLM contexts grow unbounded. ELYRA sets a strict 2,048-token cap, with a target sliding window of 1,024 tokens to leave ample headroom for model weights.

🛡️ System Prompt Preservation

The core operating instructions and safety directives are permanently pinned at index 0. They are immune to FIFO eviction loops, guaranteeing behavioral consistency.

🔄 FIFO Eviction with Priority Locks

When message total tokens exceed the budget, oldest non-system turns are gracefully pruned. High-priority mission alerts carry retention locks preventing premature discard.
